Envoyer avec Brevo

  1. Cliquez sur Export HTML.
  2. Dans Brevo : Campagnes → Créer → E-mail, puis Éditeur HTML → Importer un fichier (ou Copier le code puis Coller votre code).
  3. Envoyez-vous un test, puis programmez l'envoi.

Envoyer avec Outlook

  1. Cliquez sur Copier pour Outlook.
  2. Ouvrez un nouveau message et collez (Ctrl+V).
